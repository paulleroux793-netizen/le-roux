# ICD-10 CODES — Dr Chalita le Roux

Every line on an estimate needs an ICD-10 (diagnosis) code. Get it from the dentist's notes — never guess. These are the codes the practice uses in >95% of cases. The full SADA Quick Reference list is in `ICD 10 CODES.xlsx` for anything unusual.

## The codes we actually use

| ICD-10 | Meaning | Use for |
|---|---|---|
| **Z01.2** | Dental examination | Check-ups, cleanings, x-rays, whitening, fissure sealants, denture work — anything with no active disease |
| **K02.8** | Other specified dental caries | Most fillings, RCT, crowns, restorative work where decay is documented |
| **K02.9** | Dental caries, unspecified | Same as K02.8 when the notes don't say which surface |
| **K04.0** | Pulpitis | RCT where the pulp is inflamed |
| **K04.5** | Chronic apical periodontitis | RCT where there's a chronic infection / abscess at the root tip |
| **K05.x** | Gingivitis / periodontitis | Perio cleaning, deep cleaning (scaling & root planing). Use K05.0/K05.1 (gingivitis) or K05.2/K05.3 (periodontitis) |
| **K08.1** | Loss of teeth | Dentures and implants (missing teeth) |
| **K08.9** | Disorder of teeth/supporting structures, unspecified | Denture / prosthetic work when K08.1 doesn't fit |
| **K00.6** | Disturbances in tooth eruption | Wisdom teeth, impactions, kids' eruption issues |
| **K07.6** | Temporomandibular joint disorders | TMJ-related splints / nightguards |

## Quick mapping by treatment

- **Filling / crown / RCT (decay):** K02.8 (or K02.9)
- **Root canal (infected/inflamed):** K04.0 (pulpitis) or K04.5 (abscess)
- **Check-up / clean / x-rays / whitening:** Z01.2
- **Extraction (decayed/failed tooth):** K02.9 or K08.1
- **Wisdom tooth / impaction:** K00.6
- **Denture / implant (missing teeth):** K08.1
- **Gum treatment / deep clean:** K05.x
- **TMJ splint:** K07.6

> Wrong ICD-10 = the medical aid rejects the claim. If the diagnosis isn't clear from the dentist's notes, ask before sending.
