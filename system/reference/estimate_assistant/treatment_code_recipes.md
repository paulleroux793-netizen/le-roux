# TREATMENT CODE RECIPES & BENCHMARKS — Dr Chalita le Roux

What codes we normally charge for each treatment, plus rough price benchmarks. Built from real treatments billed Jan 2025 – Mar 2026 (patient details removed).

> ## ⚠ READ THIS ABOUT PRICES FIRST
> **Prices are NOT fixed in this document.** The practice management system (Elixir) updates all fees **every year**. The rand figures below are **rough benchmarks only**, to sanity-check an estimate — they are **not the price to quote**. Always pull the **current year's price from Elixir** before giving a patient a figure. This assistant's real job is to get the **codes, canal counts, and ICD-10** right — not to set prices.

> ## 🧮 GIVE MORE CODES, NOT FEWER
> When building an estimate, **list every code that could legitimately apply** — setup, anaesthetic, x-rays, the procedure, materials, lab, sundries. It is far better to include a code the dentist then removes than to forget one and under-charge. When you're not certain, say it like this:
> *"These are the codes we've seen used for this in the past — you most likely only need to charge these. Please confirm with Dr Chalita / the dentist which codes to include for this specific patient. Here are the codes and what each one means: …"*

## How every estimate is built

1. **Setup codes** (almost always): 8109 × 2, 8110 × 1, 8145 × 1 (per quadrant numbed), 8304 × 1 (per arch isolated).
2. **X-rays** as taken: 8107 (single tooth), 8112 × 2 (bitewings), 8115 (panoramic), 8197 (CBCT).
3. **The procedure codes** for the specific treatment (below).
4. **ICD-10** on every line (see ICD-10 file).

## Fillings
- **Codes:** setup + filling code per tooth.
  - Front tooth: **8351 / 8352 / 8353** (1 / 2 / 3 surfaces)
  - Back tooth: **8367 / 8368 / 8369 / 8370** (1 / 2 / 3 / 4+ surfaces)
  - Very large filling: **8398** (used in place of 8370)
- **Rule:** one filling code per tooth per visit; one line per tooth.
- **ICD-10:** K02.8 / K02.9
- **Benchmark:** a single filling is a low-hundreds-to-~R1,500 range item; multiple fillings add up. *Check Elixir for the current per-surface fee.*

## Simple extraction
- **Codes:** setup (often no 8304) + **8201 × number of teeth** (+ 8104 if emergency, + 8220 if sutured, + 8107 if x-ray taken)
- **ICD-10:** K02.9 / K08.1
- We do **not** use 8202.

## Surgical extraction / wisdom tooth
- **Codes:** setup + **8937 × number of teeth** + 8220 (sutures) + 8107 or 8115 (+ 8104 if emergency)
- We use 8937 even for impacted teeth (8941 only for full-bony, rare).
- **ICD-10:** K00.6 (impaction) else K02.9 / K08.1

## Check-up / clean
- **Codes:** 8109 × 2 + 8110 + **8101** (or 8104 limited) + **8112 × 2** + **8115** (panoramic, unless recent) + **8159** (clean) + **8162/8161** (fluoride) + 8121 (photos, optional) + 8197 (if a CBCT is done)
- **ICD-10:** Z01.2
- **Benchmark:** recall check-up vs full new-patient work-up differ a lot — *check Elixir.*

## Whitening
- **Codes:** 8109 × 2 + 8110 × 1 + 8304 × 1 + **8159** (clean, always) + **8308 × 2** (upper + lower arch).
- **8304 is charged once** (rubber dam covers both arches in one sitting); **no 8145** (not anaesthetised).
- **Package price:** sold as a fixed package — **R 7,800 target total**; **+ R 1,500** if the patient takes the Polar Light Whip. *Confirm the current package price with the practice — it may change yearly.*
- **ICD-10:** Z01.2 (or K02.9)

## Root canal therapy (RCT)
- **Setup:** 8109 × 2 + 8110 + 8145 + 8304 + **8107 × 4–6**
- **Plus (include all that apply — lean towards more):**
  - **8124** — pulp / vitality test (diagnosis)
  - **8639** — endodontic instruments (file kit)
  - **8306** — cost of MTA (the endo repair material — common on molars / pulp caps / perforation repair)
  - **8398** — core build-up (default-include on molars)
  - **8165** — sedative filling if treatment spans two visits
  - **final filling** to seal the access cavity (8367–8370 posterior / 8351–8354 anterior)
- **Tooth-type code — SEE CANAL TABLE BELOW.** (Splitting prep + obturation: 8332/8333 prep + 8335/8336/8337 obturation instead of the combined 8338/8339/8340.)
- **Re-doing an old root canal (re-treatment):** 8334 (first canal) + 8323 (each extra, anterior/PM) or 8324 (each extra, molar) instead of 8338/8339/8340.
- **ICD-10:** K04.0 (pulpitis) / K04.5 (abscess) / K02.8

### RCT canal table — which code by tooth number
| Tooth type | FDI tooth numbers | Canals (typical) | Code |
|---|---|---|---|
| **Anteriors** (front: incisors + canines) | 13–11, 21–23, 33–31, 41–43 | 1 | **8338 × 1** |
| **Premolars** (upper & lower) | 14–15, 24–25, 34–35, 44–45 | 1 (sometimes 2 clinically) | **8338 × 1** — *practice bills premolars as 8338 even if 2 canals* |
| **Upper molars** | 16–18, 26–28 | 3 (rarely 4) | **8339 × 1 + 8340 × 2** (4-canal: 8340 × 3) |
| **Lower molars** | 36–38, 46–48 | 3 (rarely 4) | **8339 × 1 + 8340 × 2** (4-canal: 8340 × 3) |

> **In one sentence:** front teeth and premolars = 8338. Molars = 8339 + one 8340 for each extra canal (so a normal 3-canal molar = 8339 + 8340 × 2).

## Crown (CEREC ceramic)
- **Codes:** setup + 8107 × 2 + **8409 + 8560 + 8570 + 8146** (all four, every crown). Add 8398 (build-up) or 8376 + 8379 (post) if needed.
- **Re-crown:** also **8135 per old crown removed** (+ 8138 if removing a post).
- **ICD-10:** K02.8 / K02.9

## Bridge (3-unit)
- **Codes:** setup (2 visits) + **8443 × 2 (retainers) + 8415 × 1 (pontic) + 8447 × 2 (provisionals — DON'T FORGET) + 8146 × 2 + 8560 × 3 + 8570 × 3**. Add 8516 to remove an old bridge.
- **Maryland bridge:** 8443 × 1 + 8415 × 1 + 8146 × 1 + 8560 × 2 + 8570 × 2.
- **ICD-10:** K02.8 / K08.1

## Implant (4 phases)
- **Phase 1 (placement):** setup + 8107 × 3 + **9183 + 9187** + 9189 + 9190 + 8220 (+ 8767 + 8770 if bone graft) (+ 8121 photos)
- **Phase 2:** 8131 + 8109 + 8110
- **Phase 3:** 8600 + 8109 × 2 + 8110
- **Phase 4 (crown):** setup + **8536 + 8670 + 8560 + 8570 + 8367 + 9188 + 8099**
- **ICD-10:** K08.1 / K02.8

## Implant maintenance
- **Codes:** 8109 × 2 + 8110 + 8304 + **8590 × number of implants** + 8159 + 8162 (+ 8591 if repair, + 8670 if screw/coping replaced)
- **ICD-10:** K08.1

## CBCT (3D scan)
- **Codes:** 8109 × 2 + 8110 + **8197** (TMJ series 8198 not used)
- **ICD-10:** Z01.2

## Full denture
- **Codes:** setup (several visits) + **8231** (both arches) or 8232 / 8233 (single arch) + **8099** (lab — mandatory) + extractions (8201 × N / 8937) if needed. Over-denture adds 8600 / 8654 / 8670.
- **ICD-10:** K08.1

## Partial denture
- **Codes:** setup + tooth-count code **8234 / 8235 / 8236 / 8237 / 8238 / 8241** + **8255 clasps** + **8099 lab** (+ **8281 cast frame** if Cobalt-Chrome).
- **ICD-10:** K08.1 / K08.9

## Denture reline / repair
- **Codes:** 8109 × 2 + 8110 + **8273** (+ 8269 repair, + 8271 marking) + 8099. We don't usually use 8267.
- **ICD-10:** Z01.2

## Splint / nightguard / retainer
- **Codes:** 8109 × 2 + 8110 + **8169** + lab codes **9301 + 9327 + 9330 + 9571 + 9779** (+ 8104 if standalone consult). Retainers may add 8159 + 8162.
- **ICD-10:** K02.9 (K07.6 if TMJ)

## Theatre & in-chair sedation
- **Theatre codes:** **8140** + the clinical codes (fillings/extractions/etc.) — place of service **24 Day Clinic / Hospital**.
- **In-chair sedation codes:** **8144** (+ the anaesthetist's flat fee as a custom line) + clinical codes — place of service **11 Consulting room**.
- **Process:** both need **medical-aid pre-authorisation**; anaesthetist is **Dr Anjo Rossouw (+27 82 885 5653)**. See the SOP §5.18 for the full booking + payment workflow.
- **Payment:** patient pays our fees in full before the procedure; in-chair sedation is fully out of pocket. See SOP.
