# CHARGE CODES GLOSSARY — Dr Chalita le Roux (COMPLETE)

Plain-English meaning of **every SADA tariff code the practice has actually charged** (built from real billing Jan 2025 – Mar 2026). Use this to explain what a code is for and to make sure no code is forgotten.

> ⚠ **This glossary lists codes and what they're FOR — not the current price.** Prices update yearly in the practice system (Elixir). Always confirm the live fee there.
>
> 🧮 **Always lean towards MORE codes, not fewer.** When you build an estimate, include every code that legitimately applies (setup, x-rays, materials, lab, the procedure itself). It's better to list a code and have the dentist remove it than to forget one and under-bill.

## NOT estimate codes (ignore these on the system — they are payments/admin)
- **P-CARD / P-ELEC / P-CASH** — payment receipts (card / EFT / cash)
- **DISCOUNT** — a discount line
- **0000** — custom / sundry line (e.g. the Polar Light Whip whitening add-on)
- **C-codes (C3, C5, C7, C9, C13, C14, C16, C31, C32, C35, C62, C93, C99, C122)** — internal consumable / sundry codes
- **B01 / B02** — internal bundle / package lines
- **CT JOURNAL** — accounting journal entry

> If a code isn't in this glossary, look it up in the full SADA codebook (`CHARGE CODES EXPLAINED.xlsx`) or ask Dr Chalita. **Never invent a code.**
