# Practice logo drop-in

Place the practice logo here as **`logo.png`** (or a transparent SVG exported as PNG):

    public/brand/logo.png

It will then appear automatically on the invoice + estimate documents (and anywhere `BrandLogo`
is used) — no code change or rebuild needed. Until a file is present, a clean gold "Dr Chalita le
Roux" wordmark is shown as a fallback.

Recommended: a transparent-background PNG, roughly 600×200px (or the SVG from
`14. Marketing/19. Logo`). Keep it crisp for printing.
